# Microswift Standard Library Shims

This code is derived from the Swift project, essentially by copying just the bits needed for the micro swift standard library and no more than is needed.

There is probably a lot of code in here that is not needed but was easier to copy, so don't assume all of it is load bearing.

There are some additions just for micro swift and the S4A IDE.
